# Anmol Srivastava | Personal Portfolio

The source code for my corner of the internet. This is where I dump my projects, test out new frontend ideas, and keep track of what I'm building. 

## What's Inside

* **Smooth Navigation:** Heavy use of animations for a clean, app-like feel. 
* **Built-in Resume Viewer:** Read my CV right in the browser without having to download a PDF.
* **Vibes:** Seamless background audio integration. 
* **Project Deep Dives:** A breakdown of my work, the stacks I use, and the problems they solve.

## The Stack

This repo specifically highlights my frontend skills, but my day-to-day work involves a lot more backend architecture and API engineering:

* **Languages:** JavaScript, Python, SQL
* **Backend & Cloud:** Node.js, Flask, Deno, Supabase, Render
* **AI Shenanigans:** Claude API, Google Gemini, Shivaay

## Featured Projects

* **MUJ Navigator:** A Progressive Web App (PWA) built so people can actually find their way around the Manipal University Jaipur campus.
* **Veritas:** A pre-consultation medical bot. It uses the Claude API to collect and structure patient symptoms before they see a doctor.
* **Verdian- Smart waste management system:** A practical full-stack waste management application bridging Python and the JS ecosystem.

## Run It Locally

Want to mess around with the code or use it as a template?

```bash
# Clone it
git clone [https://github.com/anmolsrivastava073/portfolio.git](https://github.com/anmolsrivastava073/portfolio.git)

# Move into the directory
cd portfolio

# Install dependencies and spin up the dev server (assuming npm/vite)
npm install
npm run dev
```
